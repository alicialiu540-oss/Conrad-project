# Expert reference sources

The LSTM prototype uses short clips derived from the Cambridge University Hospitals early-knee-exercise series as expert reference movements.

Source page: https://www.cuh.nhs.uk/our-services/physiotherapy-outpatients/outpatient-physio-resources/resources/knee/early-knee-exercises/

The accompanying manifest lists all 20 exercises, original video links, timestamps, camera views, and review notes. The video clips are intentionally excluded from this public upload because the source page does not provide a clear redistribution licence.

Keep the original clips locally or in an approved private classroom storage location until reuse permission is confirmed.
